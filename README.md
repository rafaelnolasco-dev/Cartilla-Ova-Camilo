# Cartilla para docentes · OVA 1.0 «Las aventuras de Camilo»

Cartilla interactiva para docentes del objeto virtual de aprendizaje (OVA) **«Las aventuras de Camilo: secuenciación y abstracción»**, un proyecto en Scratch para estudiantes de grados sexto y séptimo del modelo Caminar en Secundaria.

- **Autores:** Peña Ossa, J. D.; Nolasco Rojas, R. R.
- **Dirección:** Michael Stiven Valencia Villa
- **Institución:** Licenciatura en Tecnología, Universidad Tecnológica de Pereira (2026)
- **OVA en Scratch:** https://scratch.mit.edu/projects/1440470067

## Contenido de esta carpeta

| Archivo | Qué es |
|---|---|
| `index.html` | La cartilla interactiva completa (un solo archivo, con las tipografías incluidas). |
| `assets/img/` | Capturas del OVA, personajes, botones y bloques de Scratch. |
| `cartilla-imprimible.pdf` | La versión para imprimir (tamaño carta). |
| `CITATION.cff` | Datos de citación (GitHub y Zenodo los leen solos). |

| `.nojekyll` | Le dice a GitHub Pages que publique los archivos tal cual. |

Para verla sin internet: abra `index.html` en cualquier navegador. Lo que el docente escribe (notas, listas, rúbrica) se guarda solo en su propio navegador.

## Cómo publicarla

### 1. GitHub Pages (página web pública y gratuita)
1. Cree una cuenta en https://github.com y un repositorio público, por ejemplo `cartilla-ova-camilo`.
2. Suba todo el contenido de esta carpeta (botón **Add file › Upload files**). Incluya el archivo oculto `.nojekyll`.
3. En el repositorio vaya a **Settings › Pages**. En *Source* elija **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarde.
4. En uno o dos minutos la cartilla queda en `https://SU-USUARIO.github.io/cartilla-ova-camilo/`.

### 2. Zenodo (DOI permanente para citarla en la tesis)
1. Entre a https://zenodo.org con su cuenta de GitHub.
2. En **GitHub** (menú de su perfil en Zenodo), active el interruptor del repositorio `cartilla-ova-camilo`.
3. En GitHub cree una versión: **Releases › Create a new release**, etiqueta `v1.0`, título «Cartilla para docentes OVA 1.0». Publíquela.
4. Zenodo archiva esa versión y le asigna un **DOI**. Copie el DOI en `CITATION.cff`, en la sección «Cómo citar» de la cartilla y en las referencias de la tesis.

### 3. Repositorio Institucional UTP
- Entregue la cartilla (el PDF y el enlace a la versión web o el DOI) junto con la tesis, siguiendo el proceso de la Biblioteca Jorge Roa Martínez.
- Diligencie la **Licencia de autorización** de la Universidad (formato 124-F35) para que el documento quede en acceso abierto.
- El repositorio le dará un enlace permanente del tipo `https://hdl.handle.net/11059/…`.
